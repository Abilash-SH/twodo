# iPhone validation for native motion and chat

Use a paired test account and install the PR build with **Share → Add to Home Screen**. Close and reopen it after an update so the service worker finishes switching versions. Test light and dark appearance, portrait and landscape. The automated suite uses Abilash and Deiva against fake Firebase; it does not contact production.

## Automated evidence and limits

Run `npm ci --ignore-scripts`, `npm run typecheck`, `npm run build`, and `node tests/velocity.cjs`. Build and serve the online and offline fixtures as described in `tests/README.md`, run `tests/e2e/test_1_pair_and_chat.py` first, then tests 2–7.

The additional assertion suite checks full-distance back tracking (including task text), held cancellation, angled flicks, repeated touch-send focus on the iOS haptic fallback path, simulated viewport resize sequences, no chat blur including pseudo-elements, long-code create/unlock/change, encrypted secret storage, photo/Settings/effects/timer dismissal, Reduce Motion and all 1,440 colour-stop combinations. The negative sign-in check in test 3 deliberately receives HTTP 400 from fake Firebase.

Chromium cannot reproduce Safari's compositor, real keyboard animation timing, the system status bar/Island, Face ID prompts or physical iPhone haptic output. Those remain device checks, not claims of automated coverage. Check them on the PR build before merging; main deploys automatically.

## Security review

No encryption, sync format, data sanitization, storage key, dependency, production configuration, CSP or third-party-origin changes. Passcodes stay in transient component state and flow directly into the existing vault methods. Existing vault tests check encrypted-at-rest storage, wrong-code rejection, background auto-lock and secret exclusion from ordinary storage/counts/views. Passcode-change coverage verifies that changing the wrapper leaves the encrypted vault payload unchanged. Gesture listeners/timers are cleaned up, cancellation never commits a dismiss, and no HTML strings or inline scripts are added to product code.
